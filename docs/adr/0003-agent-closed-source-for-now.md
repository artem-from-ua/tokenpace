# ADR-0003: Mac-агент поки закритий; ліцензія — відкрите питання

## Контекст

Раніше припускалось, що Mac-агент буде open-source під Apache-2.0 (мотив — довіра до поводження
з OAuth-токеном). Це рішення передчасне: модель розповсюдження, монетизація та юридичні аспекти
ще не визначені.

## Рішення

Mac-агент **наразі закритий**. Питання open-source та конкретної ліцензії — **відкрите**,
повернемось до нього пізніше (ймовірно ближче до публічного релізу / Фази 3).

## Наслідки

- Репозиторій — приватний.
- Аргумент «довіра через відкритий код» лишається валідним мотивом на майбутнє, але не є
  зобов'язанням зараз.
- Коли рішення ухвалять, цей ADR буде доповнено новим (із посиланням), а не переписано.
